# Telegram-чаты: отдельный экран

## Зачем
Сообщения из Telegram-чатов выглядят как поток реплик и плохо читаются в общей ленте. Поэтому чаты выводятся на отдельной вкладке.

## Как работает
- Источники Telegram классифицируются как `channel` или `chat`.
- Сообщения из `chat` исключаются из общей ленты.
- Для чатов доступен отдельный экран `/projects/<id>/chats/`.

## Экран «Чаты»
- Список чатов слева.
- Диалог в центре с группировкой по ответам.
- Поиск по сообщениям (`?q=`) и лимит выборки (`?limit=50|100|200`).
- Выбор сообщений и создание сюжета как «диалог».

## Диагностика источников
На странице источников есть вкладка «Сервис»:
- Сводка каналов/чатов/unknown.
- Список Telegram-источников, которые не удалось распознать.
- Кнопка «Обновить метаданные Telegram» для повторной классификации.

## Замечания
Если Telegram-источник не распознаётся (`unknown`), укажите `@username` или invite-link вместо ссылок вида `t.me/c/...`.
