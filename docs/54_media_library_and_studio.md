# Media Library и Media Studio

## Цель

Описать новую структуру работы с иллюстрациями: централизованную медиабиблиотеку на
уровне проекта и отдельную медиа-студию для генерации изображений. Документ
фиксирует пользовательские сценарии, ключевые сущности и требования к доступу.

## Контекст

Редактор создает сюжет, получает итоговый текст статьи, затем переходит в отдельный
раздел Media Studio для генерации изображений. Отобранные изображения попадают в
Media Library и только оттуда прикрепляются к сюжету.

## Принципы

- Медиабиблиотека принадлежит проекту и разделяется между всеми участниками проекта.
- Доступ к медиабиблиотеке определяется участием пользователя в проекте.
- Сгенерированные изображения не должны «загрязнять» медиабиблиотеки других
  проектов.
- Генерация изображений отделена от основного процесса редактирования сюжета.

## Модель доступа и совместная работа

### Проекты и участники

- Проект может иметь несколько пользователей-участников.
- Участники проекта видят одну общую медиабиблиотеку.
- При создании нового проекта у медиабиблиотеки нет медиа-объектов.
- Если к проекту подключается новый пользователь, он автоматически получает доступ к
  медиабиблиотеке проекта.

### Изоляция между проектами

- Медиа-объекты привязаны к проекту.
- Пользователь может видеть медиа только в проектах, где он участник.
- Генерации и загрузки пользователя появляются только в медиабиблиотеке текущего
  проекта, а не в глобальном списке.

## Media Library (медиабиблиотека)

### Назначение

Единое хранилище всех медиа, относящихся к проекту: загруженные вручную,
импортированные из постов или сгенерированные в Media Studio. Это банк иллюстраций,
из которого редактор выбирает изображения для сюжета.

### Основные функции

1. Список и поиск по всем медиа проекта.
2. Фильтрация по источнику (upload, generated, imported), дате и тегам.
3. Просмотр карточки медиа и метаданных.
4. Выбор изображения для вставки в сюжет.
5. Управление статусами (draft, approved, archived) и удаление.

### Сущности (концептуально)

- MediaItem
  - project_id
  - source (upload / generated / imported)
  - title, description, tags
  - author_id
  - status (draft / approved / archived)
  - created_at

## Media Studio (генерация изображений)

### Назначение

Отдельный интерфейс для генерации изображений с помощью нейросетей. Он привязан к
выбранному сюжету, но не перегружает основной редактор сюжета.

### Сценарий использования

1. Редактор пишет сюжет и получает итоговый текст.
2. Переходит в Media Studio.
3. Выбирает нужный сюжет из списка проектов (по умолчанию — последние).
4. Видит готовый текст сюжета и подсказку: предложенную идею изображения.
5. Настраивает генерацию, получает варианты.
6. Отбирает изображения и сохраняет их в Media Library.
7. Возвращается в сюжет и выбирает иллюстрации из Media Library.

### Повторное использование подсказок

- На странице генерации отображается готовый текст сюжета.
- Система автоматически формирует краткое описание того, что можно изобразить.
- Используется уже существующая логика генерации идеи изображения из процесса
  создания сюжета (реиспользование текущей функции).
- Редактор может принять предложенную идею или отредактировать промпт вручную.

### Основные функции

1. Выбор сюжета, связанного с генерацией.
2. Автозагрузка текста сюжета и идеи изображения.
3. Редактирование промпта.
4. Настройки генерации (модель, формат, количество вариантов).
5. Просмотр результатов, удаление неудачных.
6. Сохранение выбранных вариантов в Media Library.

### Сущности (концептуально)

- GenerationSession
  - project_id
  - story_id
  - author_id
  - parameters
  - created_at
- GeneratedImage
  - generation_session_id
  - status (selected / discarded)
  - exported_to_library (bool)

## Связь между модулями

- Media Studio использует сюжет проекта как источник текста и контекста.
- Сгенерированные изображения доступны в сюжете только после сохранения в Media
  Library.
- Media Library служит общим хранилищем для всех участников проекта.

## UX-детали

- Media Studio имеет отдельный вход в навигации.
- В Media Library отображаются изображения проекта, независимо от автора.
- В сюжете отображается только медиабиблиотека текущего проекта.
- В списке проектов для Media Studio показываются только проекты, где пользователь
  является участником.

## Риски и ограничения

- Нужна строгая привязка медиа к проектам для предотвращения утечек между командами.
- В медиабиблиотеке быстро растет объем, нужны фильтры и теги.
- Стоимость генераций требует ограничений и логирования по проекту.
